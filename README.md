# Реестр договоров

Веб-приложение для учёта договоров, контрагентов, судебных дел и корпоративных актов.

## Быстрый старт

1. Зарегистрируйтесь на [github.com](https://github.com)
2. Создайте новый репозиторий (название любое, например `reestr`)
3. Загрузите в репозиторий **все файлы** из этой папки:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `snap.json`
   - `.nojekyll`
   - `README.md`
4. Включите GitHub Pages:
   - Settings → Pages → Source: Deploy from a branch → Branch: `main` → Folder: `/ (root)`
   - Save
5. Через 1–2 минуты сайт будет доступен по адресу:
   - `https://ВАШ_НИК.github.io/reestr/`

## Настройка Dropbox

1. Откройте приложение по ссылке GitHub Pages
2. Зайдите в **Настройки**
3. Введите App key, App secret и код авторизации Dropbox (как обычно)
4. Готово — данные синхронизируются через Dropbox, сайт работает из любого браузера

## Безопасность

- Пароли хешируются через SHA-256
- Токен Dropbox шифруется AES-GCM перед сохранением
- Все данные хранятся в вашем Dropbox, не на GitHub
